# 使用指南

## 管理界面

服务启动后直接访问 `http://127.0.0.1:58390/`（端口可用 `WinQuota__ApiPort` 修改），也可通过托盘程序的原生窗口打开（见下文）。

### 今日状态

- 每 5 秒刷新的剩余时间、运行中进程（含 PID）、整机使用状态
- 规则卡片显示已用 / 总额度（含临时奖励）、剩余时间与进度条
- 额度耗尽且还有剩余延期次数时，卡片上出现“延期 N 分钟（今日还剩 M 次）”按钮，使用者可自行点击，无需管理员 PIN
- 最近 7 / 30 天使用统计柱状图

### 限制规则

- 启用 / 禁用开关、修改额度（工作日 / 周末）
- 临时奖励（+15 / 30 / 60 分钟，仅当天生效）
- 编辑规则详情：名称、匹配进程列表、提前提醒阈值（分钟 CSV）、延期次数与时长
- 删除规则（连同用量历史）

### 添加应用

- “限制指定应用”：从正在运行的程序中选择（含图标 / 产品名 / 路径，支持过滤），或手动输入进程名（每行一个，多个进程共享额度）
- 可选配置完整路径匹配（防改名 / 复制绕过）与数字签名者（一键读取当前 exe 的签名者 CN，最强的防绕过识别方式）
- 提前提醒阈值、耗尽后允许延期的次数与时长
- “限制整机使用”：统计电脑实际使用时间，锁屏、空闲与系统睡眠不计入，耗尽后自动锁定

### 设置

- 管理员 PIN 设置 / 修改（PIN 用于保护规则修改等敏感操作）

## 安全模型

- API 仅监听回环地址并校验 Host 头；查询类接口免鉴权，规则修改等敏感操作需要 PIN（请求头 `X-WinQuota-Pin`，界面自动携带）
- 未设置 PIN 时敏感操作放行（首次使用），**建议装好后立即设置 PIN**
- 自助延期接口免 PIN，但次数与时长由服务端按规则强制

## 桌面程序（托盘 + 主窗口）

`WinQuota.Tray.exe` 是原生桌面程序（WebView2 内嵌管理界面，无需打开浏览器）：

- 启动即显示主窗口；双击托盘图标或右键菜单“管理界面”再次打开
- 关闭窗口只是隐藏到托盘，真正退出需要管理员 PIN（未设置 PIN 时直接确认）
- 鼠标悬停显示第一条规则的剩余时间，“今日状态”弹出全部规则
- 右键菜单：管理界面 / 今日状态 / 锁定电脑 / 开机自启 / 退出
- 再次运行 exe 会唤醒已运行的实例显示窗口（单实例）
- 目标机器缺少 WebView2 运行时时自动回退系统浏览器；`--minimized` 参数启动时仅驻留托盘
- 退出桌面程序不影响后台服务的限制
- 托盘在用户会话内实测键鼠空闲时间并上报服务，作为整机“正在使用”判定的优先依据（规避部分环境 WTS 锁屏标志不可靠的问题）

## 额度耗尽时会发生什么

1. **提前提醒**：剩余时间每越过一个阈值（默认 30 / 15 / 5 / 1 分钟，可按规则配置）弹一次 Toast
2. **耗尽 + 可延期**：进入宽限期（默认 5 分钟），期间不杀进程 / 不锁屏；使用者可在“今日状态”页自行延期（界面默认每次 20 分钟，次数与时长按规则配置）；宽限通知用 msg.exe 置顶弹窗，全屏游戏内也可见
3. **宽限期超时或次数用尽**：应用规则终止整棵进程树（含改名的子进程），当天再次启动会在 5 秒内被再次终止；整机规则锁定工作站（可配为仅提醒）
4. **次日零点后**：额度自动恢复，无需任何操作
